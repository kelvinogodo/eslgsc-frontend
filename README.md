# Commission Frontend

## Project summary
`commission-frontend` is a React + Vite single-page application for the ESLGSC portal. It includes public pages and role-restricted dashboard pages that integrate with the backend API.

## Problem solved
This frontend provides one interface for:

- public access to commission information and published updates
- authenticated access to admin/media/audit workflows
- employee, audit, and news management views
- retirement alert and activity monitoring views

## Features (confirmed)
### Public experience
- Public routes for home, about, services, contact, complaints, gallery, FAQ, local governments, development centers, and news pages
- Published news listing and article detail pages
- Set-password and reset-password entry pages used by invite/reset flows

### Dashboard experience
- Protected dashboard routing for roles: `SUPER_ADMIN`, `ADMIN`, `MEDIA_ADMIN`, `AUDIT`
- Super/admin pages:
  - overview
  - employees
  - news moderation
  - audit queue
  - retirement alerts
  - activity log
  - user/invite management pages (super admin only)
- Media pages:
  - news editor
  - drafts
- Audit pages:
  - pending edits
  - employee audit

### Data and auth behavior
- Axios API client with Bearer token request interceptor
- Auth context with token/user persistence in `localStorage`
- React Query for server state and cache
- Rich text news editor (TipTap) with image upload integrations

## Stack
- React 19
- Vite 7
- React Router
- TanStack React Query
- Axios
- Tailwind CSS 4
- Headless UI + Heroicons
- React Hook Form
- TipTap editor
- React Toastify

## Setup
### Prerequisites
- Node.js and npm
- Running backend API (or a reachable API base URL)

### Install
```bash
npm install
```

### Configure environment
Copy `.env.example` to `.env` and set:

- `VITE_API_BASE_URL` (example: `http://localhost:5000/api`)

### Run
```bash
# development
npm run dev

# production build
npm run build

# preview build output
npm run preview

# lint
npm run lint
```

## Project structure
```text
commission-frontend/
+-- package.json
+-- vite.config.js
+-- vercel.json
+-- src/
|   +-- main.jsx
|   +-- App.jsx
|   +-- router/         # route graph and protected routing
|   +-- context/        # auth provider/hooks
|   +-- services/       # API access modules
|   +-- pages/          # page-level screens
|   +-- components/     # reusable UI and domain components
|   +-- hooks/          # custom hooks
|   +-- lib/            # constants/utilities/query client
+-- public/
    +-- images/         # static image assets
```

## Architecture overview
```text
Browser
  -> React Router (public + protected routes)
  -> Page components
  -> Service layer (Axios)
  -> Backend API (/api/*)

State layers:
- AuthContext for token/user session state
- React Query for server-state caching and invalidation
```

## Deployment notes (confirmed)
- `vercel.json` rewrites all paths to `/` for SPA routing.
- API base URL resolution:
  - first: `VITE_API_BASE_URL`
  - fallback: `https://commission-backend-jbfq.onrender.com/api`
- Frontend build output is generated by `vite build` into `dist/`.
